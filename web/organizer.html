One-time Cloudflare setup

  1. Create the Worker bear-optimizer-api and the D1 database bear-optimizer.
  2. Add a D1 binding named DB to the Worker and a secret named ADMIN_TOKEN containing your organizer key (at least 32 random characters).
  3. Copy the Worker code below. In Cloudflare, open the Worker → Edit code, replace all placeholder code, then Deploy.
  4. Return here, enter your organizer key, and click Initialize database.
Open Worker code

The code contains no credentials. Your organizer key is the value you stored in Cloudflare's ADMIN_TOKEN secret.
